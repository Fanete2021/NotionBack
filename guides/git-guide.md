# Гайд по гиту

## Именование веток

Ветку именуем по следующей схеме:

```
{фамилия/никнейм/любой идентификатор}/NOT-{номер задачи}/{название фичи}
```

Пример: `goncharov/NOT-11/md-files`

## Husky

Husky обязателен. Хуки, настроенные в `.husky`, должны быть установлены и активны у каждого участника — коммиты и пуши, проходящие мимо хуков (например, через `--no-verify`), не допускаются.

## Pull Request

* После пуша ветки в git обязательно создаётся ПР (пулл реквест).
* Описание ПР должно содержать ссылку на задачу.
* ПР проверяется всеми участниками команды бэкенда.
* Мёрж в ветку `main` выполняет создатель ПР — он же разрешает конфликты при их возникновении.
